# eSewa WHMCS Module — ePay v2 Payment Gateway Plugin

Connect eSewa to WHMCS with this third-party PHP payment gateway module. The eSewa WHMCS plugin adds an eSewa payment button to invoices, redirects customers to eSewa checkout, and checks transaction status before recording a payment in WHMCS.

Built for businesses using WHMCS to bill for hosting, domains, and other services, this integration uses the eSewa ePay v2 payment form API.

[Download releases](https://github.com/surazdott/esewa-whmcs-module/releases) · [Source code](https://github.com/surazdott/esewa-whmcs-module) · [Report an issue](https://github.com/surazdott/esewa-whmcs-module/issues)

> Current implementation: ePay v2 checkout and request signing are present. Callback signature verification and explicit duplicate-transaction protection need implementation before production use. No end-to-end payment test or WHMCS/PHP compatibility matrix is recorded in this repository.

## Features

- eSewa payment button on WHMCS invoices, including invoices generated by orders or created manually.
- Redirect-based eSewa ePay v2 checkout.
- HMAC-SHA256 request signatures with Base64 encoding.
- Merchant Code and Secret Key settings in WHMCS.
- Test Mode setting for sandbox checkout.
- Server-side transaction status lookup on the customer's successful return.
- WHMCS gateway logging and invoice payment recording after a `COMPLETE` status response.

## Requirements

- An existing WHMCS installation and administrator access.
- PHP with cURL, JSON, and HMAC hashing support, using a version supported by your WHMCS installation.
- eSewa merchant credentials for the selected environment.
- A publicly reachable HTTPS WHMCS installation for checkout return URLs.
- Outbound HTTPS connectivity from the WHMCS server to eSewa.

The module does not implement currency conversion or currency validation. Confirm your invoice currency and settlement configuration with eSewa before accepting payments. Exact WHMCS and PHP version compatibility requires testing.

## Installation

1. Back up your WHMCS installation and any existing eSewa gateway files.
2. Download and extract a release from the link above.
3. Copy the archive's `modules` directory into your WHMCS installation root, preserving this structure:

```text
WHMCS_ROOT/
└── modules/
    └── gateways/
        ├── esewa.php
        ├── callback/
        │   └── esewa.php
        └── esewa/
            ├── helpers.php
            ├── init.php
            ├── logo.png
            └── whmcs.json
```

4. Open payment gateway management in your WHMCS Admin Area.
5. Find and activate **eSewa Payment Gateway**.
6. Enter the configuration below and save.

## Configuration

| Setting | Description |
| --- | --- |
| Merchant Code | Your eSewa product/merchant code for the selected environment. |
| Secret Key | The corresponding eSewa signing key. Keep production credentials private. |
| Test Mode | Enable for sandbox checkout; disable only after resolving the limitations below and completing testing. |

If WHMCS is installed in a subdirectory, that directory is included in the URL. You do not normally enter this URL into the module settings.

Use current sandbox credentials from the [official eSewa integration documentation](https://developer.esewa.com.np/pages/Epay). Test credentials and production credentials must belong to their respective environments.

## Payment flow

1. A customer opens a WHMCS invoice and selects eSewa.
2. The module creates a signed ePay v2 payment form.
3. The customer completes payment on eSewa's website.
4. eSewa redirects the customer to the module callback.
5. The module checks the invoice amount and queries eSewa for transaction status.
6. A `COMPLETE` response triggers payment recording and a return to the invoice.

Payment recording currently depends on the customer reaching the return callback. There is no scheduled reconciliation process for interrupted returns or pending payments.

## Frequently asked questions

### What is the eSewa WHMCS module?

It is a third-party payment gateway integration that lets WHMCS customers initiate invoice payments through eSewa checkout.

### Does this eSewa WHMCS plugin use ePay v2?

Yes. It submits payment forms to `/api/epay/main/v2/form` and generates HMAC-SHA256 request signatures. Complete production readiness has not been established; see the implementation limitations above.

### Is this an eSewa WHMCS module free download?

The project's source and release links are provided above. Licensing needs clarification: the existing README declares MIT, while `whmcs.json` declares proprietary and this checkout has no standalone LICENSE file. Confirm the license before redistributing or modifying the module.

### Is this an official eSewa or WHMCS plugin?

No. This is an independent integration by Suraj Datheputhe, unaffiliated with eSewa or WHMCS.

### Does it support refunds or subscriptions?

Automatic refunds and automatic subscription debits are not implemented. Customers can initiate payments for invoices; that is separate from automatically charging a wallet.

### What if a payment succeeds but the invoice remains unpaid?

Check the eSewa merchant transaction record and WHMCS gateway log. Confirm the customer reached the callback and check for an amount mismatch or status API failure. Reconcile the transaction before requesting another payment.
